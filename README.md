# TaskFlow

TaskFlow — backend приложения для управления задачами с личными и командными досками.

Проект разрабатывается на **Python** с использованием **FastAPI** и **PostgreSQL**. API предоставляет регистрацию и авторизацию пользователей, управление досками и задачами, а также разграничение доступа на основе ролей.


## Возможности

- Регистрация и авторизация пользователей.
- Аутентификация с помощью JWT.
- Личные и командные доски.
- Несколько пользователей у одной доски.
- Ролевая модель: `owner`, `admin`, `member`.
- Проверка членства пользователя в доске и его прав доступа.
- Хранение данных в PostgreSQL.

## Технологии

- **Python** — основной язык разработки.
- **FastAPI** — создание REST API.
- **SQLAlchemy 2.0** — ORM и взаимодействие с базой данных.
- **PostgreSQL** — реляционная база данных.
- **Pydantic** — валидация входных и выходных данных.
- **JWT** — аутентификация пользователей.

## Архитектура

Backend разделён на слои:

- `routers/` — HTTP-маршруты и обработка запросов.
- `services/` — бизнес-логика и проверки доступа.
- `repositories/` — запросы к базе данных.
- `models/` — SQLAlchemy-модели.
- `schemas/` — Pydantic-схемы.
- `db/` — подключение и настройки базы данных.

## Быстрый запуск локально

### 1. Клонирование репозитория

```bash
git clone <GITHUB_REPOSITORY_URL>
cd <PROJECT_DIRECTORY>
```

### 2. Создание виртуального окружения

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Подключение PostgreSQL

Создайте базу данных PostgreSQL и настройте строку подключения в соответствии с конфигурацией проекта.

Пример строки подключения для локального запуска:

```text
postgresql+psycopg://USER:PASSWORD@localhost:5432/taskflow
```

Имена переменных окружения должны соответствовать настройкам, которые читает приложение. Пример `.env` будет добавлен после завершения настройки конфигурации.

### 5. Запуск приложения

Из корневой папки проекта:

```bash
uvicorn app.main:app --reload
```

После запуска документация API будет доступна по адресам:

- API: <http://127.0.0.1:8000>
- Swagger UI: <http://127.0.0.1:8000/docs>
- ReDoc: <http://127.0.0.1:8000/redoc>

Команда предполагает, что точка входа приложения находится в `app/main.py`.

## API

### Авторизация

| Метод | Endpoint | Назначение |
|---|---|---|
| `POST` | `/auth/register` | Регистрация пользователя |
| `POST` | `/auth/login` | Получение JWT |
| `GET` | `/auth/me` | Получение данных текущего пользователя |

### Доски

| Метод | Endpoint | Назначение |
|---|---|---|
| `GET` | `/boards` | Список досок текущего пользователя |
| `POST` | `/boards` | Создание доски |
| `GET` | `/boards/{board_id}` | Получение доски |
| `PATCH` | `/boards/{board_id}` | Обновление доски |
| `DELETE` | `/boards/{board_id}` | Удаление доски |

### Задачи

| Метод | Endpoint | Назначение |
|---|---|---|
| `GET` | `/boards/{board_id}/tasks` | Список задач доски |
| `POST` | `/boards/{board_id}/tasks` | Создание задачи |
| `GET` | `/boards/{board_id}/tasks/{task_id}` | Получение задачи |
| `PATCH` | `/boards/{board_id}/tasks/{task_id}` | Обновление задачи |
| `DELETE` | `/boards/{board_id}/tasks/{task_id}` | Удаление задачи |

Для защищённых маршрутов используется заголовок:

```http
Authorization: Bearer <access_token>
```

### Статусы задач

- `todo` — задача запланирована.
- `in_progress` — задача выполняется.
- `done` — задача завершена.
